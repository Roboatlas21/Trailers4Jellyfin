Trailers4Jellyfin

Help

Downloads trailers for upcoming and recently released movies not in your library from TMDB/YouTube, then plays them before your movies — no Cinema Mode plugin needed.

A free TMDB API key is required. Get one here →

TMDB
Your TMDB Read Access Token (JWT) or v3 API key from themoviedb.org/settings/api.

Cinema Mode

When enabled, this plugin privately registers Cinema Mode assets with Jellyfin. The folders below do not need to be added as Jellyfin libraries, so they stay out of navigation and Recently Added.

Playback order: Trailer Pre-Roll → Trailer(s) → Feature Pre-Roll → Movie.
Leave either pre-roll folder blank to skip that stage. Users still need Cinema Mode enabled in their client playback settings.

Each Prefer unwatched option defaults to on and uses the current Jellyfin user's watched status. Existing saved choices are preserved. Watched clips remain available when no unwatched clips remain, or to fill the requested trailer count. For trailers, genre groups are chosen first. Within that group, prefer unwatched trailers, then replay the oldest-watched.

Movie trailers obey the current user's parental maximum and the movie's recognized rating. Regional certifications use the library/server metadata country, then a consistent country fallback. Unresolved ratings follow the user's Block unrated trailers preference. Run Download TMDB Trailers to refresh existing regional rating metadata.

Trailer Rotation

Keep the downloaded pool aligned with the current TMDB ranking instead of using a simple oldest-first queue.

Desired size of the current ranked trailer pool. Each run keeps trailers still in the target set, downloads up to the per-run limit, then retires out-of-target/legacy trailers as replacements arrive. Set to 0 for unlimited. Default: 100.
Trailers that any user has already watched will be deleted at the start of each download run, keeping the pool fresh.

Advanced
Full path to yt-dlp. Recommended — yt-dlp is far more reliable than the built-in downloader and handles YouTube bot protection automatically. Leave blank to auto-detect from common locations and PATH, or fall back to the built-in downloader (720p max) if yt-dlp is not found.
Full path to ffmpeg. Required by yt-dlp to merge separate audio and video streams into a single .mp4 (needed for 1080p and when yt-dlp cannot find ffmpeg automatically). Leave blank if ffmpeg is on the system PATH.
Path to a cookies.txt file (Netscape format) exported from a browser while logged into YouTube. Fixes "VideoUnavailableException" errors that occur when YouTube blocks automated requests from server IPs. Use a browser extension such as "Get cookies.txt LOCALLY" (Chrome/Firefox) to export the file, then copy it to your Jellyfin server and enter the path here. Works with both the built-in downloader and yt-dlp.
