Trailers4Jellyfin

Help

Downloads and maintains a ranked pool of movie trailers from TMDB/YouTube, then privately supplies movie and episode Cinema Mode intros without requiring helper media libraries.

Start with TMDB, then configure Movies and Shows in playback order. Discovery and pool controls follow below.

TMDB

TMDB provides movie discovery, ratings, popularity, release dates, budgets, runtimes, genres, certifications, and trailer links. A TMDB credential is required for automatic trailer downloads.

Enter either a TMDB v3 API key or Read Access Token from themoviedb.org/settings/api. Both formats are detected automatically. Default: blank.

Cinema Mode

Enables Trailers4Jellyfin's private Cinema Mode provider. Movie and episode intro files are registered privately with Jellyfin and do not need to be added as visible media libraries.

Enables Trailers4Jellyfin intros for movies and TV episodes. Individual stages remain disabled when their folder is blank, trailer count is 0, or all episode outcome chances are 0%. Default: On.

Movies

Configure what plays before movies.
Playback order: Trailer Pre-Roll → Trailer(s) → Movie Pre-Roll → Movie

Trailer Pre-Roll

Optional folder containing a bumper or intro that plays before the trailer block. One clip is selected each time. Leave blank to disable. Default: blank.
Prefer clips this Jellyfin user has not watched. Falls back to watched clips when necessary. Default: On.

Trailers

Folder where Trailers4Jellyfin stores downloaded movie trailers and JSON metadata. This folder is registered privately with Jellyfin; do not add it as a normal media library. Default: blank.
Number of downloaded trailers to play before a movie. Set to 0 to disable downloaded trailers while keeping the pre-roll stages. Default: 2.
Within the selected genre group, prefer trailers this user has not watched. Unwatched trailers are ranked by genre-match score, with current raw TMDB popularity breaking equal-score ties. Default: On.
First use trailers with direct genre matches. If none are available, try related genres, then the general trailer pool. Within the selected group, trailers matching more genres rank higher. Default: On.
Do not advertise a movie this Jellyfin user has already watched. Matching uses TMDB movie IDs. This does not delete trailer files. Default: On.
Never show a trailer advertising the same movie the user is about to watch. Default: On.

Movie Pre-Roll

Optional folder containing a bumper, studio intro, or other clip that plays after the trailers and immediately before the movie. Leave blank to disable. Default: blank.
Prefer clips this Jellyfin user has not watched. Falls back to watched clips when necessary. Default: On.

Movie trailers obey the current user's parental maximum and the movie's recognized rating. Regional certifications use the library/server metadata country, then a consistent country fallback. Unresolved ratings follow the user's Block unrated trailers preference.

Shows

Configure occasional Episode Pre-Rolls and movie trailers before TV episodes.
Playback order: Episode Pre-Roll → Movie Trailer → Episode when both are selected.
Episodes with an existing resume position are skipped.

Episode Pre-Roll

Folder containing Episode Pre-Rolls, bumpers, or other clips that may play before TV episodes. Leave blank to disable episode pre-rolls. Default: blank.
Prefer clips this user has not watched before falling back to previously watched clips. Default: On.
Chance that an eligible episode plays one Episode Pre-Roll clip and no movie trailer. Default: 14%.
Chance that an eligible episode plays one downloaded movie trailer and no Episode Pre-Roll. Default: 6%.
Chance that an eligible episode plays an Episode Pre-Roll followed by one movie trailer. Default: 0%.
Nothing: 80%. Episode Pre-Roll only + movie trailer only + both must total 100% or less.
Minimum time since the previous episode pre-roll actually started. Set to 0 to disable the time cooldown. Default: 60 minutes.
Number of fresh episode starts required after a pre-roll before another may play. Set to 0 to disable episode spacing. Default: 3.
Maximum number of episode pre-rolls allowed during the rolling time window. Set to 0 to disable this limit. Default: 2.
Time period used by the maximum-pre-roll limit. Default: 4 hours.

Trailer Discovery

Choose which movies are considered for the downloaded trailer pool. Filters are applied per TMDB source before the results are merged and ranked. A movie only needs to qualify through one enabled source.

In Theatres

Include TMDB's current Now Playing movies. Movies must also have a primary release date inside the released-movie window. Default: On.
Require at least this many TMDB user votes before an In Theatres movie can qualify. Default: 30.
Require at least this TMDB vote average. Default: 6.5.

Coming Soon

Include movies whose regional theatrical release date is within the Coming Soon window. Default: On.
Minimum TMDB vote count. A default of 0 avoids excluding major unreleased movies before they receive votes. Default: 0.
Used only by the legacy Popularity pool ranking. Coming Soon popularity is multiplied by this value before the pool is ordered. Default: 3×.

Popular

Include recently released movies ranked by current TMDB popularity. Default: On.
Require at least this many TMDB votes. Default: 100.
Require at least this TMDB vote average. Default: 6.0.

Top Rated

Include recently released highly rated movies. Default: On.
Require a larger vote sample so movies with only a few unusually high ratings do not dominate. Default: 500.

Release Windows

Maximum lifecycle age of released movies. Score mode uses the first theatrical release in the configured region, so a later re-release does not reset the movie's age. Default: 1 year.
How far into the future Coming Soon searches using the configured region's theatrical dates. Default: 6 months.

Trailer Languages

Choose which trailer languages are acceptable when TMDB provides multiple trailers. When all languages are enabled, Trailers4Jellyfin treats this as no language restriction. Default: all supported languages enabled.

Trailer Download Filters

Control how candidate movies are validated and how many new trailers can be downloaded during each scheduled task run.

Maximum number of trailer candidates attempted during one scheduled task run. A failed candidate still consumes one slot; its automatic yt-dlp retry does not consume another. Already-downloaded trailers that are skipped do not consume the limit. Default: 20.
Minimum discovery depth for each enabled source. Larger trailer pools automatically increase this depth above the configured minimum (4 pages for up to 100 trailers, 6 for 150), up to 10 pages/source. Each TMDB page contains up to 20 movies. Default: 4.
Reject movies with a reliable known TMDB budget below this amount. Unknown budgets remain eligible. Default: $500,000.
Positive TMDB budgets below this amount are treated as unreliable/unknown rather than real budget values. Default: $1,000.
Reject movies with a known runtime shorter than this. Missing or zero runtime is treated as unknown and allowed. Default: 45 minutes.
Maximum preferred trailer resolution. Default: 720p.
When enabled, do not download trailers for movies already present in your Jellyfin library. Default: Off.
Reuse an existing downloaded trailer instead of downloading it again. Default: On.

Trailer Pool

Pool ranking decides which trailers are kept. Playback priority decides which eligible trailer is shown first after parental, watched-history, and genre filtering.

Lifecycle score balances popularity, release timing, rating confidence, and proven quality. Legacy popularity preserves the previous popularity-based pool ordering. Default: Lifecycle score.
Score uses the daily ranking manifest after the selected genre tier is chosen. Popularity preserves the previous playback ordering. Default: Score.
When Score playback is selected, use PlaybackScore instead of PoolScore. The boost is strongest near theatrical release and fades quickly after opening. Default: On.
Two-letter ISO 3166-1 region used for theatrical discovery and lifecycle release dates. Default: US.
Target size of the ranked trailer pool. Each scheduled run keeps trailers that remain desirable, downloads missing higher-ranked trailers, and retires lower-ranked trailers as replacements arrive. Movies without a usable trailer do not reserve a pool slot. Set to 0 for unlimited. Default: 100.

Advanced Ranking

Minimum rating reached gradually as a released movie ages. The lifecycle model ramps from 6.0 for newer releases to this value by about 6 months after release. Default: 6.8.
Minimum vote count reached gradually as a released movie ages. The lifecycle model ramps from 100 votes for newer releases to this value by about 6 months after release. Default: 500.
Released movies at or above this rating may receive the proven-quality score floor when they also meet the vote requirement. Default: 6.8.
Vote count required before a released movie can receive proven-quality protection. Default: 1,000.

Score playback: the selected direct/related genre group is ranked by number of matching genres first, then PlaybackScore (or PoolScore when the release boost is off), PoolScore, popularity, and TMDB ID. If any trailer in the selected group is unwatched, watched trailers are excluded; oldest LastPlayed is used only after every eligible trailer in that group has been watched.

Advanced
Optional explicit path to yt-dlp. Leave blank to auto-detect it from common locations and PATH, or fall back to the built-in downloader. Default: blank.
Optional path to ffmpeg. Used by yt-dlp when separate video and audio streams need to be merged. Leave blank if ffmpeg is already discoverable on PATH. Default: blank.
Optional Netscape-format cookies.txt file. Configure only when YouTube blocks unauthenticated server-side downloads. Works with both the built-in downloader and yt-dlp. Default: blank.
